# 공개 BM 및 최종 발표 QA 기록

## 적용 범위

BM·매출 퍼널은 공식 상점·공식 공지로 직접 확인되는 **상품 구조**만 비교한다. 시장 반응은 보조 관측으로, 직접 성과 지표는 공개 확인 불가로 분리했다. 이 기준은 매출·전환·반복 구매·고가치 결제 성과를 추정하거나 상품별 매출을 꾸미지 않기 위한 것이다.

## 근거 상태

| 상태 | 대시보드 처리 |
|---|---|
| `[확인]` | 공식 상점·공지에서 확인한 유형, 상품/제도, 공지 시점 가격·구매 제한 |
| `[관측]` | 순위, 검색 관심, 평점, 이벤트 등 시장 반응 보조 신호 |
| `[비공개]` | 정확 매출, 구매자 수, 전환·반복 구매율, 고가치 결제 비중, ARPU·ARPPU·LTV, 상품별 매출 기여도 |

## 발표 QA

| 검증 항목 | 결과 |
|---|---|
| 금지된 미조사 캐릭터 표기 | 프로젝트 전수 검색 0건 |
| 경쟁 압력 2×2 보드 | 4개 카드가 공통 역방향 순위 축과 전 기간 시계열을 표시하며, 사례 브리프와 분리됨 |
| 유저 반응 | 인사이트 카드·검색 관심 차트·스토어 평판 표의 경계·간격·높이를 콘텐츠 밀도에 맞춰 정렬 |
| 성과 필터 | 경쟁작 선택 시 메이플M 기준 KPI를 명시하고, 검색 관심은 지원 데이터 범위를 고정·안내 |
| 결론 | 공개 BM 구조·동시 관측 신호와 내부 결제 데이터의 최종 검증 필요성을 구분 |
| 화면 확인 | 1366×768, 1440×900, 1920×1080에서 주요 섹션의 헤딩·표·버튼·차트 오버플로 없이 확인 |
