# Competitor Benchmark

현재 대시보드의 경쟁 비교는 `client/src/data/dashboardData.ts`와 최종 발표·QA 문서에 반영되어 있습니다. 비교 대상은 검은사막 모바일, 마비노기 모바일, 아이온2입니다.
