## DataLab 기준

기본 차트는 공식 게임명 4개를 하나의 요청에 넣은 공통 상대지수 프레임입니다. 분석 기간은 2025-11-17~2026-08-10, 주간 39개 관측치이며 절대 검색량·시장점유율·DAU·매출로 해석하지 않습니다. 별칭·장기 요청은 검증 산출물로 분리했습니다.

## Evidence boundary

공개 BM 구조와 실제 결제 성과를 구분합니다. 전환율·재구매율·ARPU·ARPPU·LTV는 공개 자료만으로 확정하지 않으며 내부 데이터 검증 대상으로 남깁니다.
