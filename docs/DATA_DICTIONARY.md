# MARKETING QUEST Data Dictionary

아래 정의는 현재 대시보드 런타임과 검증 산출물에서 실제 사용하는 개념을 기준으로 합니다. 공개 지표와 내부 검증 지표를 혼동하지 않습니다.

| 필드·개념 | 정의 | 단위 | 기간·범위 | 출처 | 해석 주의사항 |
|---|---|---|---|---|---|
| `game_revenue_rank` | 게임 매출 순위 | 순위, 낮을수록 우수 | 39주 | MobileIndex 기반 최종 PPT 차트 캐시 | 실제 매출액이 아님 |
| `user_rank` | 이용자수 순위 | 순위, 낮을수록 우수 | 39주 | MobileIndex 기반 최종 PPT 차트 캐시 | 이용자수 절대값이 아님. 결측은 보간하지 않음 |
| `search_interest` | NAVER DataLab 통합검색 상대 관심도 | 같은 요청 최대값=100인 상대지수 | 39주, 공식명 4그룹 단일 요청 | NAVER DataLab | 절대 검색량·시장점유율·DAU·매출·직접 리텐션이 아님 |

## 고정 기준

분석 기본 기간은 `2025-11-17~2026-08-10`이며 39주입니다. 검색 관심 기본 그룹은 `메이플스토리M`, `검은사막 모바일`, `마비노기 모바일`, `아이온2`의 공식명 4개입니다. 별칭 포함·장기 기간 결과는 별도 검증 산출물이며 기본 차트에 혼합하지 않습니다.

## 내부 데이터가 필요한 항목

전환율, 구매자 수, 재구매율, ARPU, ARPPU, LTV, 상품별 매출 기여도와 고가치 결제 비중은 공개 자료만으로 확정하지 않습니다. 이 항목들은 메이플M 내부 데이터로 별도 검증해야 합니다.
