# Evidence Boundary

MARKETING QUEST의 핵심 원칙은 다음 순서를 지키는 것입니다.

> **PUBLIC EVIDENCE → PERFORMANCE SEPARATION → INTERNAL VALIDATION → DECISION SCOPE**
>
> **공개 확인 → 실제 성과와 분리 → 내부 검증 → 판단 범위**

| 공개적으로 확인할 수 있는 것 | 확인할 수 없는 것 |
|---|---|
| 매출 순위와 이용자수 순위의 관측 움직임 | 실제 매출액·절대 이용자수 |
| NAVER DataLab 상대 검색 관심 | 절대 검색량·시장점유율·DAU·매출 |
| 이벤트 시점과 순위·검색 관심의 동시 움직임 | 이벤트의 직접 매출 효과·인과관계 |
| 공개 상품·멤버십·패스·패키지 구조 | 실제 구매 행동·전환율·재구매율 |
| 검색 관심 peak 이후의 상대 잔존 프록시 | 실제 이용자 Retention |
| 검증 후보와 우선순위 | 메이플스토리M 도입 확정 또는 성공 보장 |

## 해석 규칙

매출 순위는 매출액이 아니며, 순위 변화는 방향과 상대적 위치를 설명하는 데 사용합니다. NAVER DataLab의 `ratio`는 하나의 요청 안에서 최대값을 100으로 두는 상대지수입니다. 39주 공식명 4게임 단일 요청의 공통 프레임과 별칭·장기 검증 프레임을 혼합하지 않습니다.

공개 BM 구조는 상품이 어떤 방식으로 설계되어 있는지를 보여주는 분석 가설입니다. 상품 존재만으로 결제 성과, 반복 구매 우수성, IP 콜라보 매출 증가를 주장하지 않습니다.

전환율·재구매율·ARPU·ARPPU·LTV 및 상품별 매출 기여도는 내부 데이터가 있어야 판단할 수 있습니다. 따라서 대시보드의 전략은 실험 전 검증 후보이며, 기준선·대조군·비용 한도·중단 규칙을 사전에 정해야 합니다.
