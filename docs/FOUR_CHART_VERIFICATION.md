# 4차트 경쟁 비교 보드 검증 기록

## 화면 구조

1366×768 개발 미리보기에서 경쟁 분석 화면은 아래 네 차트가 동시에 보이는 2×2 보드로 렌더링된다.

| 카드 | 표시 범위 | RE:BOOST |
|---|---|---|
| 01 | 메이플스토리M·검은사막 모바일·마비노기 모바일·아이온2 | `메이플M RE:BOOST` 마커 표시 |
| 02 | 메이플스토리M vs 검은사막 모바일 | 미표시 |
| 03 | 메이플스토리M vs 아이온2 | 미표시 |
| 04 | 메이플스토리M vs 마비노기 모바일 | 미표시 |

브라우저 렌더링에서 네 카드 모두 공통 39주 순위 축을 사용하며, 카드 폭 전체에 시계열 선·축·범례가 표시되는 것을 확인했다. 사례 브리프는 네 차트 아래에 한 줄 높이의 보조 영역으로 배치되어 그래프 세로 높이를 우선한다.

## 공통 제어와 데이터 원칙

`게임 순위`와 `이용자수`는 네 카드에 공통 적용된다. `이벤트 사례만`은 차트 선을 필터링하지 않고, 아래 이벤트 사례 브리프와 확인 이벤트 스트립을 강조하는 제어다. 검은사막 모바일의 이용자수 순위 결측은 보간하지 않으며, 데이터가 없는 구간은 원본 제한을 유지한다.

실제 브라우저에서 `이용자수` 공통 토글을 선택해 네 카드가 동시에 `USER RANK`로 갱신되는 것을 확인했다. 검은사막M이 포함된 카드에는 측정값만 표시하고 `검은사막M 34/39주 결측` 주석을 함께 노출해, 결측 구간을 보간하지 않았음을 명확히 한다.
