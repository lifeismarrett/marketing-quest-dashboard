# 최종 발표 가독성 개선 — 시각 QA 기록

**점검 환경:** 로컬 React/Vite 미리보기, 2026-08-26 KST  
**기준:** 검증된 수치·정규화·결측·근거 상태는 변경하지 않고 발표 메시지와 가독성만 조정한다.

| 화면 | 확인 항목 | 현재 확인 결과 |
|---|---|---|
| 성과 → 검색 관심 | 탭별 헤드라인 | 검색 관심 활성 시 `4사 검색 관심을 동일 기준으로 비교합니다`로 전환되며, 매출 순위 반등 문구를 주 해석으로 사용하지 않음 |
| 성과 → 검색 관심 | 차트·출처·채널 스트립 | 차트 카드가 순위 화면보다 짧아지고, 차트·상대지수 출처 주석·CHANNEL CROSS-CHECK가 밀집된 흐름으로 표시됨 |
| 성과 → 검색 관심 | 고정 KPI | 메이플M peak `0.90`, peak week `2026-07-27`, 최근 4주 `+117.2%`가 유지됨 |
| 유저 반응 | 화면 순서 | 후킹 매트릭스와 인사이트 카드 뒤에 전체 폭의 `Peak 이후 검색 관심 잔존율`, 이어서 `STORE REPUTATION`이 배치됨 |
| 유저 반응 | Retention 데이터 원칙 | M0~M5와 관측 종료 비율이 표시되고, 관측 범위 밖 값을 채우거나 연결하지 않는 구성 유지 |
| 유저 반응 | 가독성 | 검색 관심 잔존율 차트가 기존 우측 소형 카드보다 넓은 전체 폭 분석 영역으로 표시됨 |

후속 점검에서는 경쟁 압력 차트의 정확한 날짜·순위 툴팁, BM 퍼널·간소화 표, 결론의 5개 매출 발견 블록, 그리고 1280px 이상 화면 안정성을 확인한다.

| 경쟁 압력 | 4차트 보드 | 2×2 카드가 공통 `0·60·120·180·240` 역방향 축과 충분한 카드·사례 브리프 간격을 유지하며 표시됨 |
| 경쟁 압력 | 포인트 호버 | 4사 통합 차트의 유효 플롯 좌표에서 `2026.04.27 · 주간`, 메이플M `82위`, 검은사막M `157위`, 마비노기M `16위`, 아이온2 `27위` 및 역방향 순위 주석이 동시에 표시됨 |
| 경쟁 압력 | 범위 확장 규칙 | 현재 관측값은 공통 `0–240` 축을 사용하며, 구현은 관측 최대 순위가 240위를 초과하면 최대값+24위 여유를 60위 단위로 올림 처리함 |

| BM · 매출 퍼널 | 유저 퍼널 | 유입→재방문은 절제된 중립 단계로, 첫 결제·반복 결제·고가치 결제는 기존 주황·파랑·보라 계열로 강조되어 표시됨 |
| BM · 매출 퍼널 | 공개 근거 원칙 | 결제 전환율 등 비공개 성과 수치는 추가하지 않았고, `[확인]`·`[관측]`·`[비공개]` 체계가 유지됨 |
| BM · 매출 퍼널 | 비교표 가독성 | 기본 열은 게임·핵심 BM·공개 가격·퍼널 역할·근거 상태로 축소되며, 상품·구매 제한·타깃은 `공개 구조 상세` 접힘 영역으로 이동함 |
| 결론 | 논리 순서 | `EVIDENCE → REVENUE FINDINGS → BENCHMARKING CANDIDATES → ACTION PRIORITIES`가 화면에 명시됨 |
| 결론 | 5 REVENUE FINDINGS | 공개 BM 구조·관측 신호·비공개 성과를 구분한 5개 발견 블록이 기존 7개 실행 항목 앞에 배치됨 |
| 결론 | 인과 표현 | 직접 매출 효과·전환율을 단정하지 않고, `벤치마킹 후보`와 `내부 결제 데이터 확인 후 최종 판단`을 유지함 |

## 1366×768 스크린샷 점검

| 화면 | 시각 점검 결과 |
|---|---|
| 경쟁 압력 | 네 개의 순위 카드가 축·범례·X축 날짜를 카드 안에 유지하며 2×2 보드로 표시됨. 카드와 하단 사례 브리프 사이에는 별도 여백이 있어 겹침이 없음. 사례 브리프는 세로 스크롤 뒤에 이어져, 축·카드 가독성을 억지로 압축하지 않음. |
| 유저 반응 | 후킹 매트릭스와 우측 인사이트 카드가 상단 그리드에 정렬되고, 넓어진 검색 관심 잔존율 차트가 다음 분석 단으로 배치됨. 큰 차트와 스토어 표는 세로 스크롤로 이어지며 가로 잘림은 관찰되지 않음. |

| 1440×900 결론 | 5개 매출 발견 카드와 7개 실행 우선순위가 한 발표 화면에 계층적으로 표시되며, 텍스트 겹침·가로 넘침이 관찰되지 않음 |
| 1920×1080 BM | 유입→고가치 결제 퍼널, 3단계 결제 카드, 공개 근거 5열 표, 비공개 한계 고지가 여유 있는 간격으로 표시되며 세부 정보는 접힘 영역으로 분리됨 |
