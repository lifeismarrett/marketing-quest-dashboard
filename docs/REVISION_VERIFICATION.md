# 차트 보정 검증 기록

## 4사 통합 보기

개정된 개발 미리보기의 경쟁 분석 화면에서 `4사 통합`이 기본 선택 상태로 표시되며, 메이플스토리M·검은사막 모바일·마비노기 모바일·아이온2의 39주 게임(매출) 순위가 공통 역방향 축에 함께 렌더링되는 것을 확인했다. 통합 보기에는 메이플스토리M 선이 포함되므로 이벤트 마커는 `메이플M RE:BOOST`로 귀속을 명시해 표시된다.

## 개별 경쟁작 보기의 검증 기준

개별 경쟁작 탭에서는 메이플스토리M 선이 차트에 없으므로 RE:BOOST의 체크·세로선·라벨이 없어야 한다. 이 규칙은 시각적 귀속 오류를 방지하며, 순위 축·툴팁·결측값 처리·경쟁 케이스 표시에는 영향을 주지 않는다.

개정된 개발 미리보기에서 `메이플M VS 검은사막M` 탭을 직접 전환해 확인한 결과, 검은사막 모바일 단일 게임(매출) 순위 선만 표시되고 RE:BOOST 체크·세로선·라벨은 노출되지 않았다. 동시에 해당 케이스 콘솔은 검은사막 모바일 비교 사례인 `신규 캐릭터 칼리 출시`로 정상 갱신되었다.

성과 화면의 `아이온2` 단일 필터도 직접 확인했다. 아이온2 순위 선과 범례만 남고 RE:BOOST 체크·세로선·라벨은 모두 사라졌다. 반대로 기본 `ALL` 필터에서는 네 게임의 선과 `메이플M RE:BOOST` 마커가 함께 표시된다.
