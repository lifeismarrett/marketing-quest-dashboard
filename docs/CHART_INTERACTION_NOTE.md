# 참고 이미지 판독 기록

첫 번째 참고 이미지는 경쟁 압력 차트에서 데이터 포인트에 마우스를 올렸을 때, **정확한 순위와 날짜가 강조된 호버 툴팁**을 표시하라는 요구를 확인한다.

두 번째 참고 이미지는 재사용 가능한 스킬 제작 제안이며, 이번 대시보드 레이아웃·차트·상호작용 보정 범위에는 포함하지 않는다.

세 번째 참고 이미지는 향후 순위 데이터가 240위를 초과해도 공통 비교 축을 유지하면서, 관측된 최대 순위보다 여유 있는 상한으로 자동 확장하라는 요구를 확인한다. 현재 데이터에서는 0–240 축을 그대로 유지한다.

개발 미리보기의 실제 브라우저에서 네 개의 경쟁 압력 카드는 모두 `0, 60, 120, 180, 240` 축과 완전한 X축 날짜 레이블을 카드 내부에 표시했으며, Event Case Brief와 분리되어 있다. 호버 상태는 날짜·순위 툴팁과 강조점을 제공하도록 구현했으며, 자동 마우스 좌표 점검은 활성 영역의 정확한 좌표에 따라 달라질 수 있어 추가 DOM 확인 대상으로 기록한다.

첫 자동 좌표 점검에서는 네 개 툴팁 컨테이너가 모두 비활성 상태였다. 이는 포인터가 유효한 차트 플롯 좌표에 도달하지 않았음을 뜻하므로, 다음 보정에서는 투명 데이터 포인트의 활성 영역을 제공하고 플롯 좌표 기준으로 다시 점검한다.

플롯의 실제 경계를 기준으로 다시 호버한 결과, 01번 4사 통합 차트는 `1/5 주간`과 메이플M 41위·검은사막M 129위·마비노기M 12위·아이온2 15위를 정확히 표시했다. 해당 주차의 세로 가이드와 활성 점도 함께 표시되어, 발표 중 정밀 비교에 사용할 수 있다.

성과 화면에서 매출 순위는 Primary Evidence에 `87 → 34위`, `게임(매출) 순위 53단계 개선`을, 이용자수 순위는 `69 → 33위`, `이용자수 순위 36단계 개선`을 정상적으로 반영하는 것을 실제 브라우저에서 확인했다.

검색 관심 선택 시 Primary Evidence는 `SEARCH PEAK 1.92`, `최근 검색 관심 상승 신호`, `NAVER DATALAB · 최근 4주 +161.6%`로 전환되는 것을 확인했다. 섹션 전환 효과는 전역 페이지와 `.presentation-stage`의 세로 위치를 모두 0으로 초기화하도록 구현했다. 현재 데스크톱 성과 화면은 한 뷰포트에 들어와 추가 전역 스크롤이 발생하지 않았다.

1366×768 실제 브라우저 캡처에서 하단 03·04 카드의 `240` 눈금과 날짜 레이블은 카드 경계 안에 남고, Event Case Brief는 별도 간격 아래에 배치되는 것을 확인했다. QUEST LOG로 RETENTION을 선택하면 섹션 제목과 설명이 화면 상단부터 표시된다.

실제 브라우저의 문서와 메인 스테이지는 모두 가로 넘침이 없는 상태로 확인됐다. 축 상한은 현재 0–240을 유지하며, 향후 관측값이 240을 넘으면 관측 최댓값에 24위 여유를 더해 60위 단위의 공통 상한으로 확장된다.
