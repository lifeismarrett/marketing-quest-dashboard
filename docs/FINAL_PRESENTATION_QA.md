# 최종 발표 QA 기록

## 순위 축 및 4차트 비교

개발 미리보기의 경쟁 압력 화면에서 네 개의 비교 차트는 모두 `0, 60, 120, 180, 240`의 동일한 눈금을 사용하며, 축은 역방향으로 표시된다. 따라서 화면 상단의 작은 숫자가 더 우수한 순위를 뜻하고, 모든 카드가 같은 스케일에서 비교된다.

01번 4사 통합 카드에만 `메이플M RE:BOOST` 마커가 보이며, 02~04번 1:1 카드에는 RE:BOOST 세로선·라벨이 표시되지 않는다. 실제 브라우저에서 4사 통합 카드의 툴팁은 메이플M·검은사막M·마비노기M·아이온2의 같은 주차 값을 함께 표시한다.

## 발표 레이아웃

1366×768 및 1920×1080 캡처에서 4차트 보드, 압축 Event Case Brief, RETENTION 카드 경계, Store Reputation의 외곽 여백과 최종 `QUEST COMPLETE` 버튼을 확인했다. RETENTION 검색 관심 차트는 제목·보조 주석·선 그래프·범례가 분리된 흐름으로 배치되며, Store Reputation은 요약 영역과 비교표에 약 36:64의 공간 비중을 사용한다.

`이용자수` 전환에서도 네 카드가 `0, 60, 120, 180, 240`의 동일한 공통 축을 유지한다. 검은사막M은 34/39주 결측이라는 주석만 표시하며, 결측 구간의 선 연결이나 보간은 하지 않는다. TypeScript 검사와 프로덕션 빌드도 완료했다.
