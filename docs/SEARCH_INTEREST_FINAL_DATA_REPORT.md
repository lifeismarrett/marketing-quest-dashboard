# NAVER DataLab 4게임 검색 관심 — 최종 데이터 보고서

## 결론

대시보드의 기본 검색 관심 비교는 **공식 게임명 4개를 한 번의 NAVER DataLab 주간 요청에 넣은 공통 정규화 프레임**으로 완성했습니다. 기본 관측일은 2025-11-17부터 2026-08-10까지 39주이며, 기기·성별·연령은 요청에서 모두 생략하여 전체 조건을 사용했습니다. NAVER API는 동일 요청 결과의 최대 검색 비율을 100으로 두는 `ratio`를 반환하므로, 이 수치는 하나의 요청 안에서만 비교 가능한 상대지수입니다.[1]

| 게임 | 공식명 그룹 | 평균 | 최고값 / 주 | 첫 4주 → 최근 4주 | 변화 | 누적 상대지수 Proxy | 관측 종료 시 peak 대비 |
|---|---|---:|---|---|---:|---:|---:|
| 메이플스토리M | 메이플스토리M | 0.22820 | 0.89888 / 2026-07-27 | 0.22701 → 0.49296 | +117.16% | 8.89996 | 23.28% |
| 검은사막 모바일 | 검은사막 모바일 | 0.18161 | 1.09324 / 2026-03-02 | 0.18486 → 0.10394 | -43.78% | 7.08297 | 9.03% |
| 마비노기 모바일 | 마비노기 모바일 | 3.53013 | 9.43258 / 2025-12-15 | 6.17497 → 2.08635 | -66.21% | 137.67491 | 29.38% |
| 아이온2 | 아이온2 | 15.39509 | 100.00000 / 2025-11-17 | 52.70274 → 5.84069 | -88.92% | 600.40851 | 5.02% |

> **해석 경계:** ‘누적 상대지수 Proxy’는 39주 상대지수의 합이며 검색 횟수가 아닙니다. ‘Peak 이후 검색 관심 잔존율’은 각 게임의 자체 peak 대비 상대지수이고, 이용자·DAU·결제 리텐션이 아닙니다. 검색·순위·콘텐츠 반응이 같은 시점에 움직여도 직접 인과를 주장하지 않습니다.

## 품질 감사

사용자가 제공한 원시 응답과 새 공식명 검증 응답은 39개 주간 관측일과 4개 그룹 값이 완전히 일치했습니다. 응답의 `endDate=2026-08-16`은 마지막 주간 관측이 시작하는 2026-08-10의 주간 구간 끝 날짜이며, 차트에 사용한 마지막 관측 행은 2026-08-10입니다.

| 검증 프레임 | 범위와 용도 | 기본 차트 사용 여부 |
|---|---|---|
| 공식명 기본 | 2025-11-17~2026-08-10, 39주, 4그룹 단일 응답 | 사용 |
| 별칭 포함 | 동일 기간·단위·필터, 메이플M·검사모·마비노기M을 각 공식명 그룹에 추가 | 미사용; 민감도 QA 전용 |
| 장기 공식명 | 2023-08-01~2026-08-26 요청, 반환 주간 161행 | 미사용; 장기 맥락 전용 |

별칭 포함 프레임은 공통 최대값이 다시 계산되는 별도 정규화 요청입니다. 평균 지수 변화는 메이플스토리M +88.72%, 검은사막 모바일 +16.58%, 마비노기 모바일 +0.12%, 아이온2 0.00%로 확인됐습니다. 특히 메이플스토리M의 변화가 크므로, 두 결과를 혼합하지 않고 모든 게임에 같은 **공식명만** 적용한 기본 프레임을 유지했습니다.

## 대시보드 반영 범위

성과 화면의 `검색 관심` 탭은 `ALL`, 메이플M, 검은사막M, 마비노기M, 아이온2 필터에서 공식명 기본 시계열만 보여 줍니다. `ALL`은 네 선을 동시에 표시하며 색상은 메이플M 주황, 검은사막M 보라, 마비노기M 초록, 아이온2 파랑입니다. Retention 화면의 M0~M5는 peak 이후 4주 간격이며, 관측 범위를 벗어난 값은 선을 끊어 보간하지 않습니다. 범례는 각 게임의 마지막 관측 주 기준 종료 시점 비율과 peak 후 경과 주수를 별도로 표시합니다.
