# MARKETING QUEST Project Overview

## 목적

MARKETING QUEST는 메이플스토리M과 경쟁 MMORPG 3종의 공개 시장 반응, 유저 후킹 구조, 공개 BM을 비교해 메이플스토리M이 내부 데이터로 먼저 검증할 매출 성장 후보를 좁히는 인터랙티브 발표형 대시보드입니다.

## 분석 대상과 기간

| 구분 | 내용 |
|---|---|
| Target | 메이플스토리M |
| Benchmarks | 검은사막 모바일, 마비노기 모바일, 아이온2 |
| 기간 | 2025-11-17~2026-08-10 |
| 관측 | 39주 |
| 데이터 | 게임·이용자수 순위, NAVER DataLab 검색 관심, 공식 이벤트·업데이트·채널, 후킹·평판, 공개 BM 구조 |

## 분석 흐름

`시장 반응 → 경쟁 압력 → 유저 반응 → BM·매출 퍼널 → 검증 우선순위 → 전략`

대시보드는 Mission Briefing, Performance, Battle Console, Retention, Monetization Funnel, Strategy Quest, Quest Clear의 7개 발표 상태로 구성됩니다.

## MMORPG Revenue Funnel

전체 퍼널은 유입·설치·캐릭터 생성·첫 접속·초반 성장·콘텐츠 경험·재방문·첫 결제·반복 결제·고가치 결제로 나눕니다. 공개 자료는 상품 구조와 일부 시장 반응까지만 확인할 수 있으며, 실제 고객 행동과 결제 성과는 내부 검증 범위입니다.

## 5 Revenue Findings

5개 Finding은 경쟁사 공개 BM 구조, 결제 유도 구조, 신규·복귀의 첫 결제 후보, 반복·고가치 결제 후보, 메이플M 검증 우선순위를 정리합니다. 이 목록은 도입 확정안이 아니라 우선순위가 있는 검증 후보입니다.
