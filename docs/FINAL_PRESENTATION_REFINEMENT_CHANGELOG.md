## 화면별 변경

### 성과 → 검색 관심

검색 관심 탭 활성 시 주제는 `4사 검색 관심을 동일 기준으로 비교합니다`로 전환된다. 검색 관심을 매출 순위 반등의 직접 해석으로 삼지 않도록, 동일 주간·단일 공통 정규화 프레임의 시장 반응 신호라는 설명을 분리했다. 검색 차트 카드 높이를 줄이고 차트·출처 주석·CHANNEL CROSS-CHECK의 간격을 조정했다.

### 경쟁 압력

4개 비교 차트의 역방향 공통 축, 2×2 구조, 사례 브리프 분리 배치는 유지했다. 순위 툴팁은 이제 `YYYY.MM.DD · 주간` 형식의 정확한 날짜와 각 게임의 순위를 표시하며 활성 포인트를 더 명확하게 표시한다. 관측값이 240위를 초과할 경우에는 최대 관측값에 24위 여유를 더한 뒤 60위 단위 공통 상한으로 자동 확장하는 기존 규칙을 유지했다.

### 유저 반응

검색 관심 잔존율을 우측의 소형 카드 영역에서 분리해, 후킹 매트릭스와 인사이트 카드 아래에 위치한 전체 폭 분석 차트로 확대했다. Store Reputation은 그 다음 단에 유지한다. M0~M5의 실제 관측과 결측 구간을 그대로 보존했다.

### BM · 매출 퍼널

기존 첫 결제·반복 결제·고가치 결제의 3단계는 유지했다. 상단에는 유입부터 고가치 결제까지의 간결한 MMORPG 유저 퍼널을 추가했으며, 앞의 7개 단계는 절제하고 공개 근거로 분석 가능한 마지막 3개 결제 구간만 기존 주황·파랑·보라 계열로 강조했다. 비교표의 기본 열은 `게임`, `핵심 BM`, `공개 가격`, `퍼널 역할`, `근거 상태`로 축소하고, 상품·구매 제한·타깃 유저 정보는 행별 `공개 구조 상세`에 접어 넣었다.

### 결론

기존 7개 항목 앞에 `5 REVENUE FINDINGS`를 추가했다. 최종 흐름은 `EVIDENCE → REVENUE FINDINGS → BENCHMARKING CANDIDATES → ACTION PRIORITIES`다. 각 발견은 공개 BM 구조, 보조 관측 신호, 공개 확인 불가 성과를 구분한다. 직접 매출 효과·전환율·반복 구매율을 새로 주장하지 않으며, 내부 결제 데이터 확인이 필요한 항목은 `[비공개]`으로 표시한다.
